My Free-Time Companion — v4

Open index.html in a modern browser.

Features: 14 starter activities, custom ideas, dated progress journal, saved links, search and category filters, explored progress, hide/restore activities, and JSON backup export/import.

Hidden activities are not deleted. Use the “Hidden ideas” button in the header to restore them. Data is saved only in this browser on this device. Export a backup before clearing browser data or moving to another device. Importing a backup replaces the dashboard data in that browser, so export first if you want to preserve the current state.
